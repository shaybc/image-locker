# תיעוד הפרויקט Image Locker

תיקיית `docs` מכילה תיעוד מלא של המערכת בשפה העברית.

## קבצים
- `architecture.he.md` – תיאור הארכיטקטורה ושכבות המערכת.
- `code-overview.he.md` – הסבר מה הקוד עושה מקצה לקצה (Embed/Extract).
- `user-guide.he.md` – מדריך שימוש למשתמש הקצה.
- `files-and-functions.he.md` – פירוט כל קובץ וכל פונקציה/מחלקה מרכזית.

## למי זה מיועד?
- מפתחים שרוצים להרחיב את הפרויקט.
- בודקים שרוצים להבין תרחישי עבודה.
- משתמשים שרוצים להפעיל את האפליקציה בצורה נכונה.
