# מה הקוד עושה (Code Overview)

## סיכום פונקציונלי
המערכת מממשת סטגנוגרפיה לתמונות PNG תוך שילוב:
- הטמעת LSB בערוצי RGB,
- הצפנת XOR על המטען,
- Header בינארי קבוע,
- Metadata פנימי שמאפשר חילוץ עצמאי ללא קובץ צד,
- אימות CRC32,
- אופטימיזציית מיקומים בעזרת Genetic Algorithm.

## תהליך Embed בפועל
1. קריאת תמונות קלט והמרה למבנה פנימי (`PngImageData`).
2. המרת payload לבתים והצפנה (אופציונלית).
3. בניית Header עם מידות, אורכים ו-checksums.
4. יצירת מפת הטמעה (metadata) ודחיסתה.
5. המרת Header/Metadata/Payload לביטים.
6. הרצת GA כדי לבחור כרומוזום מיקומים שמפחית שינוי בערוצים.
7. כתיבת הביטים בערוצים שנבחרו ושמירת תמונת Stego.
8. חישוב מדדים והחזרת `EmbedResult`.

## תהליך Extract בפועל
1. קריאת תמונת Stego.
2. קריאת Header באורך קבוע ושחזור `HeaderInfo`.
3. קריאת metadata בהתאם לאורך שצוין ב-Header.
4. אימות CRC32 ל-metadata.
5. שחזור מפת מיקומים וקריאת payload bits.
6. אימות CRC32 ל-payload.
7. פענוח XOR (אם הוזן מפתח) ושמירה כ-PNG.
8. החזרת `ExtractionResult`.

## מנגנוני אמינות
- **Validate על פרמטרים** (למשל `GaParameters.Validate`).
- **CRC32 כפול** (גם metadata וגם payload).
- **בדיקות טווח ואורך** במבני נתונים ו-parser של header.

## מנגנוני ביצועים
- GA קטן יחסית (ברירות מחדל שמרניות) כדי לשמור על זמן ריצה סביר.
- עצירה מוקדמת ל-GA במקרה של סטגנציה.
- דיווח התקדמות לשכבת UI לאורך הפעולה.
